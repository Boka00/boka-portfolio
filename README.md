## ✨ Features

- **Responsive & Mobile-First:** Fluid layouts that adapt across ultrawide monitors, tablets, and smartphones.
- **Type-Safe Component Architecture:** Clean, modular UI components written in TypeScript with explicit typing.
- **Theme Support:** Dark/Light mode integration with persistent state using local storage.
- **Performance Optimized:** Tree-shaken bundles, asset lazy loading, and minimal runtime overhead for high Core Web Vitals scores.
- **Accessible (A11y):** Built with semantic HTML elements and accessible keyboard navigation in mind.
- **Project Showcases:** Interactive cards linking directly to live applications, repositories, and technical breakdowns.
