# Security Policy

## Supported Versions

Only the latest deployment on the `main` branch (`https://boka-portfolio.vercel.app/`) receives security updates.

| Version / Branch | Supported |
| ---------------- | --------- |
| `main`           | Yes       |
| Older commits    | No        |

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Instead, report vulnerabilities privately through one of these channels:
1. **GitHub Private Vulnerability Reporting** (preferred): Navigate to the [**Security → Advisories**](https://github.com/Boka00/boka-portfolio/security/advisories/new) tab of this repository and submit a private report.
2. **Email**: Send details (reproduction steps, affected URL/component, and potential impact) to `boka.mkrtichiani@gmail.com` with the subject `[SECURITY] boka-portfolio`.

You can expect an acknowledgment within **48 hours** and a remediation update within **7 days**.
